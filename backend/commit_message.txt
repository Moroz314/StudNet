Что сделал?

- добавил для задач поле assignee - список user_ids тех, кто назначен на задачу. Только те, кто назначен на задачу может
добавлять комментарии и вложения к ней. Если список assignee пуст - тогда все пользователи могут работать с задачей.

- поработал над валидацией и правами доступа:
    - owner может:
        - создавать/удалять проект и пространства
        - менять статус/роль участникам проекта
        - публиковать проект/снимать с публикации

    - admin может:
        - может добавлять/удалять участников из пространства, если он в нём состоит
        - добавлять/удалять/редактировать задачи в том пространстве, в котором он состоит
        - добавлять/удалять/редактировать комментарии к задаче в том пространстве, в котором он состоит
        - назначать пользователя на выполнение задачи
        - просматривать статистику

- для загрузки файлов поле workspace_id стало обязательным


- /projects/{project_id}/workspaces/{workspace_id}/tasks - изменил префикс маршрута для эндпоинтов задач
