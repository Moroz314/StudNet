# Studnet

Studnet — это современная социальная сеть, разработанная специально для студентов, чтобы упростить общение, совместную работу над проектами и поиск единомышленников.

## Описание приложения

Studnet предоставляет студентам платформу для:
- Общения в чатах (личные и групповые)
- Совместной работы над учебными проектами
- Создания и редактирования профилей
- Публикации в ленте новостей
- Обмена файлами

## Технологический стек

### Бэкенд
- **Язык программирования**: Python
- **Фреймворк**: FastAPI
- **База данных**: PostgreSQL
- **Кэширование**: Redis
- **Аутентификация**: JWT (JSON Web Tokens)
- **Хранение файлов**: Amazon S3 (или совместимый сервис)
- **Асинхронные задачи**: Celery (опционально)
- **Дополнительные библиотеки**: SQLAlchemy, Pydantic, Bcrypt, WebSockets

### Фронтенд
- **Фреймворк**: React.js (версия 19)
- **Управление состоянием**: Redux Toolkit
- **Маршрутизация**: React Router DOM
- **Стилизация**: Tailwind CSS
- **UI-компоненты**: Ant Design
- **HTTP-клиент**: Axios
- **Сборка**: Vite

### Инфраструктура
- **Контейнеризация**: Docker
- **Оркестрация**: Docker Compose
- **Сервер статики**: Nginx (для фронтенда)

## Архитектура

Проект состоит из двух основных компонентов:

1. **Backend** (`/backend`) — API-сервер на FastAPI, обрабатывающий все бизнес-логики и предоставляющий REST и WebSocket интерфейсы.
2. **Frontend** (`/frontend`) — клиентское веб-приложение на React, взаимодействующее с бэкендом через API.

Компоненты связаны через Docker Compose, что обеспечивает простое развертывание и управление зависимостями.

## Запуск проекта

Для запуска проекта требуется Docker и Docker Compose. Выполните команду:

```bash
docker compose up --build
```

или (старая версия Docker):

```bash
docker-compose up --build
```

После запуска:
- **Фронтенд**: `http://localhost:3000`
- **Бэкенд API**: `http://localhost:8000`
- **Adminer** (управление БД): `http://localhost:8080`
- **MinIO** (S3-совместимое хранилище): `http://localhost:9000`

## Дополнительно

Приложение поддерживает WebSocket-соединения для мгновенного обмена сообщениями и уведомлений о статусе пользователей (онлайн/оффлайн). Документация по WebSocket-событиям и API доступна в соответствующих README-файлах в директориях backend и frontend.
