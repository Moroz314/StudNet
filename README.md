StudNet
StudNet — платформа для студентов, школьников и молодых разработчиков, которая закрывает разрыв между авторами идей и техническими исполнителями: помогает находить команду, организовывать работу над проектом и (в будущем) проводить хакатоны прямо внутри платформы.
🔗 Демо: http://45.11.92.114:3000 🛠 Стек: FastAPI · PostgreSQL · Redis · Celery · React 19
Зачем это нужно
Мессенджеры (Telegram, Discord) и общие пространства (Notion) удобны для общения, но не подходят для структурированной разработки: задачи, код, дедлайны и отбор кандидатов теряются в разрозненных чатах. StudNet объединяет поиск команды, таск-менеджмент и работу с кодом в одном месте.
Возможности
🔍 Поиск команды и рекрутинг
Публичная карточка проекта в общей ленте
Вакансии с гибко настраиваемыми требованиями под каждую роль
Отклик кандидата с анкетой и портфолио
Коллегиальный отбор: участники команды голосуют за понравившиеся анкеты, финальное решение принимает администратор/владелец
🗂 Рабочие пространства (Workspaces)
Изолированные пространства внутри проекта (например, «Бэкенд», «Фронтенд», «Дизайн») с собственным набором инструментов:
Kanban-доска — создание, декомпозиция и трекинг задач, назначение ответственных
Интеграция с Git-репозиториями — просмотр структуры проекта и кода прямо в интерфейсе, без переключения между вкладками
База знаний и медиа-хранилище — файлы, документация, ссылки с автогенерацией превью
💬 Коммуникация
Личные и групповые чаты
Тематические каналы
Уведомления и статусы (онлайн/оффлайн) через WebSocket
🏆 В разработке
Автоматизация хакатонов и кейс-чемпионатов: загрузка кейсов партнёром, формирование команд, мониторинг прогресса (коммиты, Kanban) для жюри в реальном времени. Логика частично реализована на уровне бэкенда, пользовательский интерфейс — в работе.
Технологический стек
Бэкенд
Язык: Python 3.11
Фреймворк: FastAPI (асинхронный)
База данных: PostgreSQL
Кэширование / брокер сообщений: Redis
Фоновые задачи: Celery
Аутентификация: JWT
Хранение файлов: Amazon S3 (или совместимый сервис)
Прочее: SQLAlchemy, Pydantic, Bcrypt, WebSockets
Фронтенд
Фреймворк: React 19
Управление состоянием: Redux Toolkit
Маршрутизация: React Router DOM
Стилизация: Tailwind CSS + Ant Design
HTTP-клиент: Axios
Сборка: Vite
Инфраструктура
Docker / Docker Compose
Nginx (сервер статики для фронтенда)
Архитектура
Проект состоит из двух компонентов, связанных через Docker Compose:
Backend (/backend) — API-сервер на FastAPI: бизнес-логика, REST и WebSocket интерфейсы.
Frontend (/frontend) — клиентское React-приложение, взаимодействующее с бэкендом через API.
Запуск проекта
Требуется Docker и Docker Compose:
docker compose up --build
или (старая версия Docker):
docker-compose up --build

Текущий статус
Разработка ведётся в одиночку с ноября 2025 года. Платформа протестирована на ~10 пользователях: создание проектов и воркспейсов, публикация вакансий, формирование команд, переписка в чатах и каналах — описанный выше функционал работает в текущей версии.
